- (insight) Synthesis: three techniques converge on one MVP shape. (2) Pen/ink quality is the same idea wearing three hats across techniques: Trait Transfer's Procreate-style pressure ink, Job-to-be-Done's 'tactile pleasure so I don't quit', and One-Feature's 'de-risk the technically riskiest thing first' -- all point at ink rendering being the actual product, not a nice-to-have. Chosen MVP direction: 46 hiragana only, SM-2-lite/Leitner scheduling, self-graded pen canvas on genkouyoushi grid, local persistence, no OCR/stroke-order ML, no mnemonics/gamification/sync in v1. - (decision by user) MVP scope revised: include BOTH hiragana and katakana from day one (92 characters, not 46), interleaved, because distinguishing the two scripts for the same syllable sound (e.g. hiragana あ vs katakana ア) is itself an important thing to learn, not something to defer. Design implication: card identity must be keyed on the actual character (grapheme + script), never on the romaji/sound alone, so same-sound pairs from different scripts are always distinct cards and can be deliberately interleaved to train the discrimination.
- (decision by user) Target device confirmed: Android tablet + stylus (e.g. Samsung Galaxy Tab + S Pen).
- (decision) Pen-canvas tech approach: Kotlin + Jetpack Compose UI, androidx.ink (stable 1.0.0, released 2025-12-17: ink-authoring/ink-brush/ink-geometry/ink-rendering/ink-storage/ink-strokes) for the writing surface. Ink is built directly on Android's low-latency front-buffer graphics pipeline (GLFrontBufferedRenderer) plus the MotionPredictor library, so near-hardware-limited pen latency comes for free without hand-rolling MotionEvent batching/prediction. Pressure maps to stroke width via the Brush module; strokes are stored as vector geometry (ink-storage/ink-geometry), not raster bitmaps, which supports lossless page export and undo/erase for free and leaves room for a future stroke-comparison auto-grader. No Samsung-specific SDK needed -- S Pen input arrives as standard Android MotionEvent (TOOL_TYPE_STYLUS), so the same code works with any Android stylus. Min requirement Android 10 (API 29) for the low-latency path, satisfied by any current Galaxy Tab. Data layer: Room (SQLite) for the SRS card table (character, script, interval, due date, last result), fully offline, matching the local-persistence-only MVP cut.
