## Intent

**Problem:** A drill session never ends on its own — `position` climbs forever, there's no accuracy readout, and stepping away mid-session (backgrounded/throttled tab) leaves nothing recorded. Learners get no defined result to trust for a sitting.

**Approach:** Give a session three ways to close (explicit "I'm done" control, full-scope completion, retroactively-detected inactivity), persist a `sessions` record on every closure, and show a Session Summary screen (accuracy hero, time/reveal stat tiles, missed-chip list, closure-appropriate chip) before returning to the Scope picker.

## Boundaries & Constraints

**Always:**
- Idle detection is retroactive, never a live timer: every interaction updates `lastInteractionAt`; idle is evaluated by comparing `Date.now() - lastInteractionAt` against `idleTimeoutMs` at the next resume (`visibilitychange`/`focus`) or interaction.
- An idle closure's `date` (and the Summary's `time` stat) reflects when activity actually stopped (`lastInteractionAt`), never when the app was reopened.
- The interaction that reveals an idle session (a stroke, a button tap, a resume event) is itself dropped once idle closes the session — it is never recorded as part of the closed session.
- "I'm done" always closes with `closureReason: 'explicit'` immediately, regardless of elapsed idle time — never reclassified as `'inactivity'`.
- `cardsAttempted` = `sessionAttempts.length` (attempts, not distinct cards); `accuracy` = correct ÷ attempts, `0` (never `NaN`) when there were no attempts.
- Session persistence (`sessionRepository.add()`) is fire-and-forget, logged on failure, same as every other write in this codebase — it must never block reaching the Summary screen.
- Full-scope closure is reached via the existing deferred-advance flow (Story 1.8): grading the card that completes the scope still shows the normal toast/Undo; tapping "Next character" closes the session (no next prompt to load) instead of calling `selectNext`.

**Never:**
- No History screen or History link from Summary — that's Story 1.10, out of scope here.
- No live-reload of `idleTimeoutMs` mid-drill — Settings is unreachable while Drill is mounted (no nav path exists), so it loads once per drill entry, same as `widthPreset`/`tallies`.
- No `duration` field in the persisted `sessions` record — only `{id, date, scope, cardsAttempted, accuracy, closureReason}` (epic-fixed schema); `time` is computed in-memory for Summary display only, never persisted.

## I/O & Edge-Case Matrix

| Scenario | Input / State | Expected Output / Behavior | Error Handling |
|----------|--------------|---------------------------|----------------|
| Explicit close | "I'm done" tapped at any point (incl. mid-toast) | Closes immediately, `closureReason: 'explicit'`, `date` = now | N/A |
| Full-scope close | Last uncovered scope card graded, then "Next character" tapped | Closes with no next prompt, `closureReason: 'full-scope'`, `date` = now | N/A |
| Idle close on resume | Tab/window regains focus/visibility, `Date.now() - lastInteractionAt >= idleTimeoutMs` | Closes, `closureReason: 'inactivity'`, `date` = `lastInteractionAt` | N/A |
| Idle close on stray interaction | A stroke/tap arrives with the same elapsed-idle condition | Closes as above; the triggering interaction is dropped, not recorded | N/A |
| Zero-attempt close | "I'm done" tapped before any grade | Summary shows accuracy 0, `cardsAttempted` 0, empty missed list | N/A |
| `sessionRepository.add()` fails | IndexedDB write rejects | Summary still renders from in-memory data | `console.error`, fail-open |
| Undo on the scope-completing grade | Grade lands and covers the full scope; user taps Undo before "Next character" | Undo reverses normally (Story 1.8); scope no longer complete, drill continues | N/A |

## Design Notes

- **Why `sessions` has no `duration` field:** the epic's fixed IndexedDB schema is `{id, date, scope, cardsAttempted, accuracy, closureReason}`; `time` is only ever shown on the Summary screen the instant a session closes, from in-memory data — History (Story 1.10) never displays it, so persisting it would be dead weight.
- **Why idle closure backdates `date`/`time` to `lastInteractionAt`:** a naive `Date.now()` at the moment the tab resumes would credit (or blame) the session for however long it sat backgrounded — a decision the architecture explicitly closes (epic context, confirmed 2026-09-03).
- **Why full-scope closure rides the existing "Next character" tap instead of a new control:** Story 1.8 already defers every advance to that tap; reusing it means the toast/Undo behavior for the scope-completing grade needs no special case, and "no explicit control needed" falls out for free.
- **Why "I'm done" is never reclassified as inactivity:** the tap itself is proof of presence — gating it through the same idle check as other interactions would occasionally and confusingly relabel a deliberate explicit close as an idle one.
