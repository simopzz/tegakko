# Prose Review — PRD: Kana Writing Practice (tegakko)

This document exists to help the app's creator — acting as both PM and sole developer — lock down what v1 does before building further on it. Reader: the creator only. Style guide: Microsoft Writing Style Guide. Voice preserved: dense, technical, terse fragment-style feature descriptions, inline `[ASSUMPTION]`/`[NOTE FOR PM]` tags, and FR/glossary cross-references — none of that is touched below.

Ran after the structure lens. Per the lens contract: the italicized template-process note under old §2.3 (CUT) is skipped; fixes that would otherwise land in old §5/§6.2 or old §8/§9 are noted against their content with a pointer to the merged destination, since the merged wording doesn't exist yet for me to edit directly.

12 findings, all minor (no comprehension-blocking issues found). Ordered by comprehension impact.

| prose | §2.2 Non-Users: "This is a single-user, local-only tool with no accounts, no sharing, and no multi-user data model — **not a v1 gap to close, a deliberate boundary** (see Non-Goals)." | "...not a v1 gap to close, **but** a deliberate boundary (see Non-Goals)." | Missing "but" makes the contrast harder to parse than it needs to be; the parallel construction elsewhere in the doc ("not scoped to kanji or vocabulary in v1 — expected soon after, **but** a deliberately separate scope decision," current §5) does include it. Inserting "but" here matches that pattern. |
| prose | §2.1 JTBD, bullet 2: "Get an honest signal fast, without a guided-tracing tool quietly doing the work of remembering **for me**, and without **my own** optimism grading a wrong stroke as right." | "Get an honest signal fast, without a guided-tracing tool quietly doing the work of remembering for the user, and without the user's own optimism grading a wrong stroke as right." | The other three JTBD bullets, and UJ-1/UJ-2, stay in impersonal/third-person form ("Confirm...", "See whether...", "The creator..."). This bullet alone drops into first person ("me", "my own"), a voice shift that stands out mid-list. Recasting it to match its siblings removes the inconsistency. |
| prose | §1 Vision: "**The product's emotional hook and hardest technical bet is** ink quality: a genuine pressure-sensitive pen canvas over a genkouyoushi grid..." | Consider: "The product's emotional hook and hardest technical bet **are** ink quality: ..." | Compound subject ("hook and bet") with a singular verb ("is"). Reads as a slip on first pass even though the intended meaning (both are the same thing) is recoverable — flagged as Consider since the singular may be an intentional "these two things are one" construction. |
| prose | FR-12 consequence, §4.5: "...so replay reproduces the stroke correctly regardless of viewport size or device. `[NOTE FOR PM]` The web PoC's own storage schema used absolute viewport-pixel coordinates in a flat, ungrouped stroke list, which proved raw point-stream fidelity but **not this**." | Consider: "...which proved raw point-stream fidelity, but not **this grid-relative, card/attempt-grouped storage shape**." | "this" has to reach back across an entire inserted `[NOTE FOR PM]` sentence to its antecedent (the grid-relative storage described before the note). Naming the referent removes the reach. |
| prose | FR-13, §4.5: "The user can export all local progress data (miss tallies, attempt records, session history) to a JSON file, and import a previously exported file to restore **it**." | Consider: "...and import a previously exported file to restore **that data**." | "it" sits closest to "a previously exported file" but is meant to refer back to "all local progress data" — a brief ambiguous-antecedent moment. |

| prose | §8 Open Questions, item 4: "Exact yoon scope (FR-1): **standard set only (66 cards) or should extended** katakana loanword combinations be included too?" Making both sides a matched "should X, or Y" pair reads more smoothly. |
| prose | §1 Vision: "...so kanji and vocabulary are expected to follow within months — not the usual multi-year horizon — **reusing** the same script-aware, self-graded, weak-spot-biased shape." | Consider: "...so kanji and vocabulary are expected to follow within months — not the usual multi-year horizon — **by reusing** the same script-aware, self-graded, weak-spot-biased shape." | "reusing" grammatically trails "kanji and vocabulary," but the intended actor is the future development effort, not the content itself. Adding "by" ties the participle to the implied "following" action instead. |
| prose | FR-9, §4.4: "A session ends — and is recorded (FR-10) — when **any of**: the user taps an explicit "I'm done" control, the user completes every card in the session's selected scope (FR-2), or the user is inactive for a set idle period." | Consider: "...when **any of the following happens**: the user taps..." | "any of:" with nothing between "of" and the colon is a clipped construction; supplying the missing noun avoids the momentary stumble. |
| prose | FR-9 consequence, §4.4: "A session closed via inactivity is still recorded (FR-10) but **flagged distinctly**... **from** sessions closed via the explicit control or full-scope completion..." | Consider: "...but **flagged as distinct from** sessions closed via the explicit control or full-scope completion..." | "flagged distinctly from" is understandable but non-idiomatic; "flagged as distinct from" (or "distinguished from") is the more natural collocation. |
| prose | §8 Open Questions, item 2: "Does the miss tally (FR-6) need decay or reset over time, so **characters hard early on** don't stay overweighted **once solid**?" (slated to merge with §9 per the structure lens) | Consider: "...so characters **that are hard early on** don't stay overweighted **once they're solid**?" | Two stacked reduced-relative-clause ellipses ("characters [that are] hard," "once [they're] solid") in one short question is denser than the doc's usual register; spelling out one or both smooths the read without changing meaning. |
| prose | FR-8, §4.4: "For every attempt (one prompt cycle), the system records **a data point** beyond just the aggregate self-grade result." | Consider: "...the system records **a full attempt record** beyond just the aggregate self-grade result." | The consequences immediately below list seven distinct fields (card, timestamp, latency, stroke count, reveal-used, self-grade), so "a data point" (singular) undersells what's actually captured; "a full attempt record" better matches what follows. |
